## 3. 資料收錄原則

- **來源可追溯（Traceable Citations）**：每筆資料皆保存原始發布機關、官方 URL 與修正／查證更新日期。
- **禁止虛構案例與法條**：所有收錄之法條與職災案例僅呈現查證之官方公開內容，不自行編造未公開之事件時間、個資或條文內容。
